# sd-webui-zh_Hans-localization-forge-neo

zh_CN-Extra.json 是forge-neo本体 + 一部分插件的汉化
专为  [sd-webui-forge-classic](https://github.com/Haoming02/sd-webui-forge-classic/tree/neo) 打造的简体中文汉化扩展。

💡 项目背景：
原版 stable-diffusion-webui-localization-zh_Hans 已停止维护，且在 Forge Neo 中常出现中英混杂、术语不统一的问题。为此，我基于 AI 辅助生成，并针对 Forge Neo 的核心界面进行了重新汉化，以提供更纯粹、流畅的中文操作体验。

📦 文件说明：

zh_CN-core.json：仅限 Forge Neo 本体的汉化（适合只需汉化主界面的用户）。

zh_CN-Extra.json：Forge Neo 本体 + 常用插件的汉化（推荐大多数用户使用，覆盖面更广）。

(注：Extra 已经包含 Core 的内容，无需同时安装两个文件。)

🛠️ 安装方法：

将本仓库克隆或下载至 extensions 文件夹。

重启 WebUI，在 Settings -> User Interface -> Localization 中选择该语言包。

🤝 反馈与建议：
因使用 AI 辅助，难免存在个别翻译不当或漏翻的情况。欢迎提交 Issue 或 PR 指正，我会持续维护和更新。
